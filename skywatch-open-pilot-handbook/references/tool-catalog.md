# Tool catalog

Copy and tailor assets; do not silently change safety-critical meaning.

| User need | Asset or script | Required boundary |
|---|---|---|
| Choose a school/CFI | `assets/templates/flight-school-cfi-scorecard.md` | No ranking guarantee; user verifies credentials and fit |
| Prepare/debrief a lesson | `assets/templates/lesson-brief-debrief.md` | CFI owns instruction and endorsements |
| Set personal minimums | `assets/templates/personal-minimums.md` | Not a go/no-go authority; limits may only become more conservative without CFI review |
| Structure flight risk | `assets/templates/pave-5p-worksheet.md` | Current official sources and pilot/operator decision control |
| Compare access models | `assets/templates/rent-club-own.md` | Estimates; include non-financial constraints |
| Define aircraft mission | `assets/templates/aircraft-mission-profile.md` | No aircraft recommendation from generic data alone |
| Plan a pre-buy | `assets/templates/prebuy-scope.md` | Independent A&P/IA and current maintenance data control |
| Prepare a rental review | `assets/templates/rental-agreement-questions.md` | Not legal or policy interpretation |
| Organize year one | `assets/templates/first-year-owner-calendar.md` | A&P/IA, CFI, and approved documents control |
| Gather insurance questions | `assets/templates/insurance-question-list.md` | Licensed representative and actual policy control |
| Estimate training cost | `scripts/training_budget.py` | Not a quote; vary assumptions |
| Estimate ownership cost | `scripts/ownership_cost.py` | Not tax, finance, maintenance, or insurance advice |
| Check W&B arithmetic | `scripts/weight_balance.py` | Exact current approved data required; verify independently |

When generating a completed worksheet, keep the “Verify before acting” and “Professional review” sections intact.
